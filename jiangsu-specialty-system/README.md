# 知遥集｜江苏特色专项长期学习系统

## 现行规则与接续（2026-10-27）

先读根目录[AGENTS.md](../AGENTS.md)所链接的现行规则、连续性和反馈台账，再使用本目录模型/候选/教学协议。最新用户指令优先；公开台账与私密学习证据分开。每轮记录读取版本、实际阶段、核验结果和未解决项，写完回读。历史Day3只表示当时批次，后续按实际完成接续。

本目录是江苏省考（重点 B 类、行政执法方向）的长期研究与反馈式训练控制包。它把“江苏特色”拆成可核验模型、候选题状态、训练阶段、复测节奏与每日发布门槛。

## 单一事实源顺序

1. 知遥集在线学习连接：最新作答、复盘确认、排除学习、收藏与发布回执。
2. Notion：长期错因、知识点阶段、任务与同步批次。
3. 本目录：公开可审计的模型、题源身份、研究进度与规则。
4. 网站备份：用于历史补核，不覆盖更新的在线记录。

冲突时保留历史，按时间和证据等级解释，不静默改写。

## 每日闭环

`读取新增记录 → 分层证据 → 更新模型 → 摘取/核验候选 → 组15—20题 → 发布 → 复盘 → 间隔复测`

- 每包 15—20 题，约 40 分钟含复盘。
- 江苏模型 4—5 题，至少 2 个模型。
- 同时最多 1 个主攻模型 + 1 个到期复测模型。
- 同一微观机制一般不超过 3 题；同一大模块一般不超过 40%。
- `excludeFromLearning=true` 对诊断、降级和补练贡献均为 0。
- 未确认复盘只记录客观结果，不生成稳定心理错因。
- 只有候选状态为 `eligible` 才能进入题包。

## 隐私与公开边界

本仓库为公开仓库。这里只保存模型、公开年份/题号锚点、结构摘要、研究方法和通用核验状态；不提交私密题库原题ID、个人使用批次、答案、错因、sessionId、账号、令牌、密钥或未脱敏备份。个人候选与Day 3证据只保存在私密Notion。题位锚点只表示“已完成模型归类”，不等于题面、答案和解析已经获得独立来源核验。
