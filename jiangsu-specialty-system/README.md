# 知遥集｜江苏特色专项长期学习系统

本目录是江苏省考（重点 B 类、行政执法方向）的长期研究与反馈式训练控制包。它把“江苏特色”拆成可核验模型、候选题状态、训练阶段、复测节奏与每日发布门槛。

## 单一事实源顺序

1. 知遥集在线学习连接：最新作答、复盘确认、排除学习、收藏与发布回执。
2. Notion：长期错因、知识点阶段、任务与同步批次。
3. 本目录：公开可审计的模型、题源身份、研究进度与规则。
4. 网站备份：用于历史补核，不覆盖更新的在线记录。

冲突时保留历史，按时间和证据等级解释，不静默改写。

## 每日闭环

`读取新增记录 → 分层证据 → 更新模型 → 摘取/核验候选 → 组15—20题 → 发布 → 复盘 → 间隔复测`

- 每包 15—20 题，约 40 分钟含复盘。
- 江苏模型 4—5 题，至少 2 个模型。
- 同时最多 1 个主攻模型 + 1 个到期复测模型。
- 同一微观机制一般不超过 3 题；同一大模块一般不超过 40%。
- `excludeFromLearning=true` 对诊断、降级和补练贡献均为 0。
- 未确认复盘只记录客观结果，不生成稳定心理错因。
- 只有候选状态为 `eligible` 才能进入题包。

## 目录

- `models/model-registry.csv`：25 个江苏模型及当前阶段。
- `candidates/candidate-ledger.csv`：脱敏候选题和已用题身份。
- `progress/current-cycle.yaml`：当前周期、主攻/复测与证据。
- `day3/plan.md`：明日 Day 3 的证据边界与组卷门槛。
- `protocols/source-and-verification.md`：题源、版权、完整性和独立核验。
- `protocols/feedback-loop.md`：反馈式学习与升级/降阶规则。
- `schemas/candidate.schema.json`：候选记录机读规范。
- `audits/2026-10-26-crosscheck.md`：网站、备份、Notion、GitHub交叉核验。
- `tools/validate_ledgers.py`：台账静态校验。

## 隐私与公开边界

本仓库为公开仓库。这里只保存模型、原题ID、年份、地区、公开链接、结构摘要和核验状态；不提交完整私密题面、完整受限解析、个人答案、sessionId、账号、令牌、密钥或未脱敏备份。
