# 一次发布、两包作答

协议PAIR-20261027-v1；网站R8.8.28。现有Worker和连接工具按账号/日期只保存一条daily记录，同一天调用两次会覆盖，禁止分别发布数量和三科两次。

## 已支持R28的客户端

1. 两包各自通过质量门槛后，拼成一个`zhiyaoji-daily-v1`，date为当轮北京时间日期，title严格为`知遥集双轨｜YYYY-MM-DD`。
2. questions顺序为数推拟真5题→强化0/2/3题→数学运算6题→三科题；数量subject为数量关系，数推path必须含数字推理父标签。三科subject仅言语理解、判断推理、资料分析。
3. 保留真实原题ID、sourceQuestionId、材料键、来源和媒体，在私密payload里处理。三科14—17并覆盖三科，数量11/13/14。全文大小≤2MB，超限不丢图，优先合法外部媒体地址/更换合格题。材料不能跨两包。
4. 通过真实DailyModel.validate和DailyPairs.derive检查后，只调用一次publish_daily_training。回读当轮date/count/hash/ok；总数=两包之和。发布工具不支持未知track字段，不能靠添加字段宣称双包已生效。
5. 首页按subject拆成数量稳分/三科进阶；子包采用完整规范化内容SHA256作为dailyPackHash。各自独立session、题号、答案、草稿和复盘；另一包更新不改变本包hash。父包focus不进入子hash。旧题包不自动拆分，旧版已开始整包会话保留原记录。
6. 有实际作答的有效未完成子包受保护。已有子包原题面/顺序/来源均不改动；若只更新另一包须先完整读取受保护子包原payload并原样拼回、校对子hash不变。无法可靠读取则不覆盖，准备候选并报告。已完成旧日期不阻塞新日期。
