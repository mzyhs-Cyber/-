## 目录与初始盘点

- `01-quantity/source-index.csv`：84条近年非江苏省考题源索引，按数推六入口、运算六组初筛。原始题面仍在授权私密来源。
- `01-quantity/local-checks.csv`：10道文本数推已逐项独立计算、逐选项核验并与题库答案一致；尚未完成发布时实时去重、所有参考解析媒体与严格同构复核，不是10道eligible。
- `01-quantity/radical-fallback.csv`：近期省外根式严格同构池仍有缺口；新增3条原机构公开旧讲义来源，全文已取得，数学版式仍需逐图核验，不能冒充近年真题或可发布题池。
- `02-three-subjects/source-index.csv`：118条去重题源候选，按15个入口初筛；使用原25模型台账做第二步严格映射，粗标签不等于G01/G03等江苏模型。
- `INDEX.json`为初始候选统计；`pair-policy.json`为组卷政策；`PUBLISH_PROTOCOL.md`为一次发布/两入口协议。

索引按真实来源去重，同一题在多卷出现不算多道新题。索引是可持续提取的来源目录，不是公开私密题库的副本。不得把完整题干/选项/解析、原私密bank ID、个人作答/笔迹提交Git。公式/图片不能按文字摘要判已读；共享材料必须完整读取并整组选择。

## 数推五题怎么配

先按已核对江苏B历史五题的外形与难度组一组盲测，常规起始为整数变式2、小数1、分数1、根式1；按实际锚点允许整数1、小数1、分数2、根式1。它是训练模板，不宣称官方每年固定小题型配额。整数位含差分、幂次、因数/短递推、数位拆分；不要求一天练完全部规律。

前5题隐藏模型标签、答案与方法提示，避免全变成一种规律。后2—3题优先当天暴露的形式缺口/到期复测，无法预知当天结果时依据最近有效反馈，题目仍须未做或明确计划复测。无合格强化可不加；缺拟真五题或运算6题则停止该包，报告缺口，不以普通整数凑根式位。

运算6题沿有限稳分路线：主模型3题＋旧模型复测2题＋做/跳取舍1题。取舍题有完整标准答案，训练识别停止条件，不故意放错误题。不把不纳入的历史记录恢复纳入。

## 三科怎么配

默认言语4/判断6/资料5；例如完整篇章5题时可5/5/5；资料两组3＋2也须完整。三科都有题，整包14—17。江苏专项一般4—5题且至少2个不同模型，优先既有S/A和当前主攻/复测；数量题不重复计入三科专项，C级通用题不占专项名额。若完整篇章5题占满专项目标，只在总量及质量允许下补另一模型并记录例外，不能拆篇章凑配额。

每条学习流最多1主攻＋1到期复测。各流按“6次学习＋第7次检测”实际完成次数接续；三科保留既有进度，数量无可靠状态才从探索性诊断开始。未确认/排除记录只作允许的客观信息，不形成个人弱点结论。

## 入池与反馈

`snapshot-indexed/lead → source-read → content-complete → independently-solved → cross-checked → model-matched → live-dedup → eligible → used/retest-due/hold`。

逐条保留来源、年份原题号、完整材料/图片检查、独立解法、答案核验、模型不变量与改动、难度依据、选择理由、去重时间和使用批次。当前两份来源索引均未标eligible；10道独立计算也不能绕过后续门槛。私密逐题核验、个人证据及阶段进入现有Notion；Git仅写脱敏统计和研究结论。

每次先读取网站最新确认复盘和Notion有效版本，exclude贡献为0、不生成被排除题的个人解析；A/A1/A2、提示与重做分开。按范围给正确率分母、原题号/小题型及待核结果。用同型未见题、跨次训练与延迟复测检验，单次全对不称稳定。模型与具体停止条件见plans/quant-half-plan.md；保留原25模型身份。
