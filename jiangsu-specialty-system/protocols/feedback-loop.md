# 反馈式学习协议

## 证据分层

1. 已完成且复盘确认、未排除：可更新模型阶段与安排补练。
2. 已完成但未确认：只保存选项、正误、用时、收藏等客观事实。
3. `excludeFromLearning=true`：保留原始成绩，但不触发补练、不降低掌握度。
4. 本人错因：与AI推断分开保存；空反馈不能被补造成“粗心”或“不会”。
5. 未完成：不计完成次数，不推进周期。

## 训练阶段

`待诊断 → 基础识别 → 同构新题 → 易混辨别 → 情境迁移 → 间隔复测 → 初步稳定`

按实际完成的6次学习推进，第7次使用未见题混合盲测。日期变化不自动切换主线。

## 升级参考

- 至少6道不同题；
- 跨至少3次已完成训练；
- 至少5题正确；
- 至少2道无提示迁移；
- 通过一次延迟复测。

正确但A1/A2、蒙对、提示后正确或记住原答案，不计独立掌握。一次全对先用1—2道稍进阶新题验证，不全面升档。

## 难度调整

- 连续2次可比训练约90%以上，且A确定、无提示、用时合理：下一批只提高一个维度。
- 约70%—85%且仍有真实错误：保持主难度，修具体卡点。
- 连续低于约60%或暴露先修缺口：降低出错维度并补最小前置，不清空其他能力。
- 每包同时保留巩固、当前主训练和少量进阶；不故意塞偏题来压正确率。

## 每日输出验收

- 15—20题；
- 江苏模型4—5题且至少2模型；
- 个人纠错、到期复测、相邻迁移和江苏模型均可追溯到证据；
- 盲解页不暴露答案、模型标签或一秒触发器；
- 发布成功只认 `publish_daily_training` 返回 `ok=true`、实际题数与hash；
- 自动任务 `completed` 或 `no_update` 不能替代业务回执。
