# 题源与核验协议

## 来源优先级

1. 用户已授权的私密完整题库：用于检索与组卷，完整内容不进入公开仓库。
2. 官方大纲、公告与公开原卷：用于范围和锚点。
3. 原发布机构公开解析、合法可读讲义或字幕：用于方法和边界交叉核验。
4. 近5年国考、外省省考、事业单位真题：用于日常同构迁移。
5. 模拟题：只作候选，必须明确标注，不得冒充真题或江苏必考。

近期江苏省考真题优先保留阶段检测，不在日常训练中批量耗用。

## 候选状态机

`lead → source-read → content-complete → independently-solved → cross-checked → model-matched → eligible → used → retest-due → retired`

- `lead`：只有标题、摘要或搜索线索。
- `source-read`：已实际读取正文或完整原题入口。
- `content-complete`：公共材料、题干、选项、答案和必要图片完整。
- `independently-solved`：不照抄解析，已独立求解。
- `cross-checked`：重要新模型或争议结论已核对第二来源/原卷。
- `model-matched`：写清关键不变量、江苏锚点与改变的一维。
- `eligible`：去重通过，可进入每日题包。

## 硬性核验

- 材料组不可拆散凑数。
- 图片题必须逐图检查，不能只凭OCR文字。
- 排列、真假、固定名额、一拖多逻辑题必须验证可行解存在，并逐项核对问法和答案唯一性。
- 原题ID、canonicalId、题面指纹、近期学习记录四层去重。
- 轻改不得改变条件、含义、答案或增加理解难度，并保留原题身份和修改说明。
- 有争议、答案冲突、缺材料、媒体不可读或版权边界不清的候选进入 `hold`/`retired`，不得凑数发布。

## 公开仓库边界

允许：模型ID、题号、年份、地区、原题ID、公开链接、结构摘要、核验状态、独立答案是否一致。

禁止：完整私密题面、完整受限解析、个人答案和错因原文、sessionId、账号与密钥、未脱敏备份。
