# R8.8.23 草稿按钮归属与复盘位置

R8.8.23：以已交付R8.8.22为基线。新增draft-owner-review.js：noteOwnerIndex独立于滚动/落笔会更新的toolIndex；草稿开启后只允许打开题的按钮高亮和关闭，其他题禁用，关闭后恢复。新增笔迹记录draftOwnerQuestionId与draftSurfaceKey，逻辑归属固定在打开题，物理坐标仍按原题/材料表面保存，不迁移历史笔迹，不改Router/Notebook/存储schema。复盘退出、后台/页面隐藏时仅保存题ID、展开状态和滚动位置；按北京时间当天、账号、练习隔离，明确点击题号优先，次日失效，复盘新笔迹仍临时。

截图纠正：用户要求渐变和边框对齐，并非整题铺色。新增review-surface.css只把材料复盘栏原父容器的横向/顶部内边距移到题卡内，文字坐标保持；原90px渐变、颜色、透明度不变，灰色手写和夜间不受影响。主bundle及全部旧CSS与R22逐字一致；仅入口/SW缓存增加补丁。实际ReleaseExam/Router跨界线段、归属按钮、序列化/撤销重做、复盘同日重开/跨日/账号/异步及旧R17—R22回归通过Node隔离测试。未部署、未做iPad实机或CSS像素级验收。
