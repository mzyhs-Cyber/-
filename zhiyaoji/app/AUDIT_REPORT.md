# 知遥集 R8.8.51｜笔迹控件与材料切换减负

基线为已交付 R8.8.50 完整包；修改前 60 个部署资产逐字节一致。当前目录不是 Git 工作树，本轮未提交 Git、未生产部署。现行规则更新为 RULES-20261029-v18。

## 实际定位和修改

ReadingControls 初次绑定及从材料切回主列表时，原代码逐个测量排除按钮并立即移动、改样式，最后对整卷每道题调用 refreshAnswer。后者重复查询整页、更新时钟并替换未变化的 SVG。普通控件更新还会重复清空空工具容器、重写笔按钮的未变化属性。这些是代码和前后对照能复现的额外工作，不据此宣称已经确定原 iPad 卡死的唯一原因。

现在先集中读取按钮原位置，再批量移动；绑定时直接更新对应行、选项、标签与排除按钮，取消整卷逐题刷新。仅在图标确实改变或缺失时替换 SVG，空容器及未变化的属性保持。笔迹所有者接管、按钮原对象、选中/排除/ARIA 状态、恢复原位置与触摸区域保持。

图标对照使用已有正确图标标记的控件；新页面和新材料的控件仍需首次初始化。实际500题整套用例累计绑定16096个控件项，图标初始化/重建2048次，其余复用。

这些是调用、DOM 操作及读写交错计数，不是实际浏览器强制重排次数、设备帧率或提速百分比。135题几何读取总量仍为1655次，但集中在移动前，保留原位置测量语义。单个排除项变化时保留其余3个图标；绑定不修改作答模型，恢复后无重复按钮。完整控制器验证所有者切换后仅一个活动笔按钮。

诊断 D2-r8-51 新增控件绑定/恢复次数、累计控件数、绑定图标重建数与最近/最长耗时，只有计数和时间，无题目、答案、账号或凭据。正常使用没有新增弹窗。
