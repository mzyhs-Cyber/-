# R8.8.74｜图片预加载与定点出题权重

本包以 R73-gray3 为基线，保留字体变灰和横线效果，可整体部署到原项目。

图片预加载：最多4个预加载任务，当前题与下一题题图优先；完成后续填队列，换题丢弃过时的未开始任务。未打开的解析图不占预加载名额，完成/失败/退出释放临时对象。滚动调度不再依赖是否开启草稿。图片清晰度、笔迹像素密度和题卡按需渲染保持。

定点训练：纳入的非蒙错100、非蒙超时错70、收藏50、不纳入的非蒙普通错与非蒙超时对25、明确蒙错10、蒙对5。同题取最高基础分；明确蒙答不因收藏抬高，做得快本身不判蒙。不同原题反复错每次加25%至多2倍，近期程度与定点反馈参与排序；同型新题确定答对且有效用时正常后逐步降权。

保留现有分科配额（言语10、逻辑判断8、资料5、数推7）、细题型匹配、难度近邻、分散出题和完整材料要求。原题仅在已有到期记录、至少间隔3天且新题匹配不足时少量补充，最多每科1题、全组2题，并标注“到期原题复测”。组卷给出预计时长，作为软约束，不保证实际耗时。

普通试卷及定点训练复盘的“错误原因”弹窗均可标记“确定／不确定／蒙”，保存到原复盘记录。

今天已经成功生成或开始的题单原样保留；新权重用于下一份新题单。后台只接收计时、收藏、信心等轻量选题信息，不带笔迹或完整题面。新代码不改作答历史、题目身份、数据库、笔迹、同步和服务端实现。

程序与隔离联动检查已通过；报告见本包“程序验证_R74.json”。预览服务不可用，未做真实浏览器画面或 iPad 长时验收，不将程序检查等同实际设备效果。
