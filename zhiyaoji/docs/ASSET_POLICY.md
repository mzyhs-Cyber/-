# 资产保存边界

`app/` 保留当前附件中的 22 个原样部署文件；不是从旧版本拼接。原 ZIP 及每个文件的 SHA-256 见 SOURCE_MANIFEST。

不提交：原 ZIP 重复副本、完整 JSON 备份、真实题库与图片、账号身份/恢复码、诊断长日志、.env、用户照片和个人信件。birthday.html 的原始字节仅在用户附件内可用，不将照片或信件复制进文档。即使仓库为私人，也不改变这个排除决定。

新对话开发普通刷题功能只需要 app 代码；涉及生日页或组装完整部署包时，须取得该单一原文件或原 ZIP。本地补齐时运行 scripts/package_deploy.py，脚本只校验和打包，不提交 Git、不执行部署、不覆盖生产。

题库版本不能用题量替代。DATA_CONTRACT 只提供字段名、类型、数量、导出时间和 SHA-256，不含原题或学习内容。实际完整备份仍由用户持有。

既有公开仓库与其历史内容未在本工单改动。不得把其旧公开资料授权扩展为允许公开本次私人题库或用户数据。
