# 知遥集现行执行规则

版本：RULES-20261027-v2。用户要求规则、连续性与反馈在GitHub记录并遵守。本页为现行规则入口；最新明确用户指令优先，旧需求被替代时保留历史并写明替代关系。

## 每次开工

1. 读取当前分支HEAD，再读本页、[连续性](CONTINUITY.md)、[反馈台账](FEEDBACK_LOG.md)、[当前状态](../PROJECT_STATE.md)、[当前工单](../ACTIVE_TASK.md)、[开发约束](../AGENTS.md)。研究任务另读Issue #5及模型台账；按需读取代码，不重扫全部旧窗口和ZIP。
2. 核对“代码已实现、测试通过、已提交、已部署、实机验收”五种状态，分别报告。仓库HEAD不证明线上已部署；任务completed不证明题包已发布。
3. 先核对是否已有同一工单、有效进行中题包或最新复盘版本；只处理当前范围，沿用既有记录与稳定ID，不重复建系统、自动任务或模型。
4. 修改前记录基线、最新要求和复现；完成后写入反馈状态、变更、实际测试、剩余问题与下一步，提交后回读远端HEAD/树/相关文件。公开记录仅存脱敏信息。
5. 规则改变时同步本页、反馈台账、连续性入口及受影响的已有任务提示词；不因更新规则立即重发当天训练或覆盖用户作答。

## 开发与数据保护

- 以当前已核实版本为基线做小范围修改，保留旧版本，不整包回退或混入旧版。r7清单只证明历史来源，不是当前代码相等目标。
- 保留主库mzy-study-clean-v2、IndexedDB version 2、schema 3及cold/hot/meta/state；题目/材料/attempt/session身份、历史、收藏、笔迹、媒体、导入查重、备份恢复未经验证不得更改。
- 现有公开仓库允许提交脱敏代码和项目档案；不提交账号密钥、真实备份、完整私密题库、个人逐题作答、笔迹正文、私人生日页、照片或信件。个人学习证据进入既有私密Notion体系，与其他学习主体隔离。
- 当前仍无本工单生产部署授权。打包、提交、PR均不自动代表部署；不强推、合并或发布生产。后续明确授权以用户指令为准。
- 完整部署ZIP首层有index.html，保留真实私人birthday；公开代码排除私人资源，不生成占位素材冒充完整包。
- 涉及笔迹或同步，按隔离测试验证写入、重开、缩放、材料切换、证据冻结、断网、重复上传、冲突及账号隔离；合成测试不冒充iPad验收。不凭猜测改笔迹算法或宣称找回数据。

## 已确认的产品行为

- 限时演练、整卷模拟、专项选择按账号和北京时间当天记忆；同日返回不强迫重选，次日更新。复盘题号/阅读位置保留一天，复盘临时新笔迹可不保留。
- 模拟卷按年份、上下半年、中文/阿拉伯/全角期数从近到远；例如33期在32期前。
- 字号变化保持当前阅读锚点；答题卡关闭重开保留滚动位置。禁止引入无关横向拖动、深色实底或大范围样式变更。
- 笔记/收藏控件使用R19已验收的30px命中区与间距；排除选项控件维持原范围。不要因后续工单重做触控区、暂停样式或笔迹曲线。
- 笔迹草稿逻辑归属为打开它的题，滚动/跨题书写不自动转移高亮。另一题未高亮笔记按钮可点一次接管，再点关闭；接管前完成旧笔画，原笔画归属不追溯改写。物理坐标与原始向量保持。
- 渐变与题卡边框对齐，保留原渐变颜色和90px范围，不擅自整题铺色。可见分隔线与题目/草稿边界一致。
- 答题卡同模块只出现一次，原题号和跳转对应；仅新建daily训练按模块及完整材料单元稳定排序。已作答历史不重排，不改原题号、作答或笔迹对应。
- 导出只细分判断为图推/类比/逻辑判断/定义判断，言语为言语填空/篇章阅读；其他原分类、格式和功能保留，未知细类不静默丢题。
- 慢题判断兼容有效数字字符串和历史失配快照；有效冻结判定保留，区分题型未匹配/缺少有效用时/材料组计时不足，不篡改原计时。

## 复盘与反馈

- “复盘上传”只上传文字、错因、纳入状态和确认；首次缺云端作答时可补白名单题面/作答/用时，仍不带笔迹、草稿或交卷笔迹证据。不回退整账号笔迹同步。本机笔迹与已有云端笔迹引用保留；独立账号同步另按既有规则运行。
- 同一练习可重复上传，按稳定sessionId更新原记录；最新reviewRevision/确认签名决定有效版本，清空、纳入反转也须覆盖，不重复计数。
- 政治理论、常识判断、数量关系中非数字推理默认不纳入；数字推理及其他模块沿用原错题/未答/收藏规则。手动选择优先，包括旧版明确选择；只写错因不自动纳入。数量未识别为数字推理时默认不纳入，可手动恢复。
- 默认排除是复盘证据范围，不擅自推导为永久禁止整个模型或删除原成绩。excludeFromLearning=true的该次证据贡献为0，不生成该题个人解析、补练或降低掌握，修改排除后撤回旧贡献。
- 只对已确认且纳入证据归档长期诊断；未确认只记客观/探索信息。本人错因、AI推断与可观察事实分开。排除选项、单次慢题、一次错误或全对均不直接证明心理原因/稳定掌握。
- 简报给范围、纳入/排除数、对错未答待核、正确率分母、小题型与原题号、待解析数。不会读取笔迹的接口不得声称分析笔迹。

## 每日组卷与连续性

- 每批15—20题、约40分钟含复盘；一般江苏专项4—5题、至少2模型；同一微观机制一般最多3题、同一大模块一般最多40%。个人纠错/复测/迁移按有效证据调整，不机械套配额、不凑数。一拖多保留完整材料，按小题计数。
- 使用已有训练体系，按实际完成的6次学习+第7次检测推进；不按自然日强推Day、不重置旧进度、不永久锁定Day3。最多1个主攻+1个到期复测模型，切换须记录证据及理由；有作答的有效未完成训练不盲目覆盖。
- 阶段：待诊断→基础识别→同构新题→情境迁移→间隔复测→初步稳定。升级参考至少6道不同题、跨3次训练、至少5对、至少2道无提示迁移及一次延迟复测；这是启发式，不是科学测量分数。D+3/7/14复测按表现调整，漏做不算完成。
- 难度以结构、步骤、表示转换、干扰、材料负荷、有效正确率、信心和耗时综合判断；不单靠题库正确率或混合卷总分。看最近2—3次约10—20道可比未见题，样本不足谨慎判断。单批近全对先增加1—2道有先修的进阶验证；连续高信心高正确且用时合理才提高一个维度；低正确或先修缺口则降阶。A/A1/A2、提示后正确、蒙对、原题重做分别记录。
- 默认数推0—1题；数推明确主攻且负荷允许时最多2题。可有2—3道已有先修挑战题，未学困难变式最多1道。新题仍须标准答案/参考解析；排除的是本人的后续个人解析与诊断贡献。
- 题源优先近5年国考、外省省考、事业单位、江苏事业单位可靠真题；近期江苏省考稀缺题保留检测。公开资料按许可使用，保留原题身份/来源/图片；模拟、轻改、自编明确标识，不冒充原题。
- 每轮围绕具体模型与本人卡点开展多来源定向检索；标题/摘要/无字幕视频仅是线索。发布前实时去重、读全题面/公共材料/选项/图片、独立求解、答案核验、结构同构核验；排列/真假/名额题检查可行性和答案唯一。未解决争议、缺图缺材料候选不发布。
- 江苏模型沿用25模型台账与稳定ID。其余23模型已分级：S为G01/G03/L02/L03/V01/Q01/K01；A为G06/L01/L04/L05/Q02/D01/C01；B为G02/G05/V02/V04/Q03/D03/D04，仅有个人适配/迁移依据才选；C为V03/C02，不计江苏专项。D02/G04按当前主攻/复测台账核验，不永久固定。G02/G05为父模型子变式，G02/G03/G05缺稳定近年省外严格同构池，不用普通图推凑数。
- 盲解前不暴露答案/方法标签。作答后错题与A1/A2按完整公共材料、题干、四选项、本人所选和正确选项全文、依据、最快法、切入条件与理由、诱因、错因及触发器解析；高信心全对可简短核对。
- 网站记录→私密Notion归档→模型阶段/到期任务→候选核验→题包→新反馈；按稳定身份和反馈版本幂等更新。公开Git只记模型研究、规则、产品反馈和脱敏核验摘要，不放个人原始作答。
- 发布只认当轮日期、题数、hash及成功回执；复查run_id/时间，不复用旧日回执冒充。失败/超时记录断点，结果不明先核对，不盲目覆盖。Git/Notion写失败如实记录，不能虚报；安全且规则/证据充分的部分继续推进。

## 数量稳分补充｜QS-HALF-20261027-v1

用户目标为数量争取对一半：常见20题结构下暂拆为数推4/5、数学运算6/15，先6→8→10，以可比预算内两次未见题检测验证，不把目标当已掌握或每卷必有配额。执行[数量稳分路线](https://github.com/mzyhs-Cyber/-/blob/feature/jiangsu-specialty-system-v1/jiangsu-specialty-system/plans/quant-half-plan.md)中的六类数推入口、六组运算模型、适用条件、第一步与跳题规则；不铺满数量课程。新路线不改原25江苏模型身份，也不把通用数量题都算江苏特色。

普通跨科日包15—20题内，数量暂2—3题（数推0—1、白名单运算1—2），替换原题位；完整材料/到期主线占位可减1—2。数推明确主攻最多2题，仍按既有最多1主攻+1复测及江苏专项4—5题/至少2模型/模块上限执行。新增目标先作少量探索诊断，不清空已有主线。不纳入默认及手动覆盖仍有效，不因建立路线恢复排除证据。复杂工程调度、复杂几何、排列证明、多层最值第一阶段暂缓；若可识别题数不足10，先验证缺口后只增一个备用小模型。争议/缺图题不得算稳题。只在未见题无提示结果、信心、耗时及复测均支持时称稳定。
